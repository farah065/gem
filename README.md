# Anubis
## About the Game
Realise your eternally bound duty as god of the afterlife. Collect back what was wrongfully taken and claim the souls of those undeserving. An isometric dungeon roguelike inspired by old Egyptian mythology and gods.

Anubis is collecting as many of the gods' souls as he can to revive them and judge them for their actions. For each boss fight Anubis enters and finishes, he gains the soul of one god. The goal for the player is to defeat all the gods and beat the game. Each run can last anywhere from a few minutes (if they lose immediately) to an hour.

This project is a small prototype for a game concept created for the Video Game Design course (DMET909) at the German University in Cairo. It goes up until the first boss fight with the god of chaos, Seth. Check it out on [itch.io](https://pixlfar.itch.io/anubis)!
